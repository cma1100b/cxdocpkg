# CX Document Packages

## Introduction

A set of LaTeX document classes and packages for CX project documentation.

### Scope

This repository hosts the source files and examples for the CX project
ocumentation LaTeX packages and document classes.

### Goal

The goal of this project is to provide a native set of premade LaTeX tools that
ensure a consistent style across all CX project documents.
